## Setup
1. `cd backend && npm install`
2. Copy `backend/.env.example` to `backend/.env` and fill in the values
3. `npm run migrate:up`
4. `npm run seed`
5. `npm run dev`

## API collection
Open the `postman/` folder in Postman, or import the files from it.
Select the "IRCTC local" environment and run the requests.
